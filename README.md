# Homebrew Tap

Personal Homebrew tap for tools by Andhi Jeannot.

## Installation

```bash
# Add the tap
brew tap andhijeannot/tap https://github.com/andhijeannot/homebrew-tap

# Install tools
brew install <tool>
```

Or install directly:

```bash
brew install andhijeannot/tap/<tool>
```
