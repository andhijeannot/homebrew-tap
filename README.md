# andhijeannot/tap

## How do I install these formulae?

`brew install andhijeannot/tap/<formula>`

Or `brew tap andhijeannot/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "andhijeannot/tap"
brew "<formula>"
```
